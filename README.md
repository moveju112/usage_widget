# AI Usage Tray

Windows 작업표시줄에 **Claude Code** 와 **Codex** 의 사용량을 보여주는 작은 위젯입니다.

시계 왼쪽, 작업표시줄 안에 붙어 있습니다. `H` 는 5시간 한도, `W` 는 주간 한도입니다.
50% 미만은 초록, 75% 미만은 노랑, 90% 이상은 빨강으로 표시됩니다.

## Claude 사용량 조회 방식 변경 안내

일부 사용량 조회 도구 이용 후 **Claude 계정이 정지됐다는 공개 신고**가 있어,
잠재적인 제재 위험을 줄이기 위해 조회 방식을 변경했습니다.
다만, 사용량 조회가 정지 원인으로 공식 확인된 것은 아닙니다.
([공개 신고 사례](https://github.com/sheprd-labs/sheprd/issues/708))

- 위젯이 Claude 로그인 토큰을 가져오거나 서버에 직접 요청하던 방식을 제거했습니다.
- 이제 **공식 Claude 데스크톱 앱의 기록**을 읽습니다. 앱을 백그라운드에서 실행해 두면 약 **15분 간격**으로 갱신됩니다.
- 원형 게이지 아래 숫자는 Claude와 Codex 모두 **사용률(%)**로 통일했습니다.

Claude 앱을 완전히 종료하면 갱신이 멈추며, 30분 이상 지난 값은 흐리게 표시됩니다.
6시간 이상 지난 값은 `--%`로 표시합니다. 앱 기록에는 초기화 시각이 없어 Claude의 정확한 남은 시간은 표시하지 않습니다.

이번 v1.0.47 배포는 Windows용입니다. Linux 배포 파일과 매니페스트는 v1.0.41을 유지합니다.

## 설치

1. [usage_tray.exe](usage_tray.exe) 를 받아 원하는 폴더에 둡니다
2. 더블클릭하면 실행됩니다 — Python 설치는 필요 없습니다
3. 트레이 아이콘을 우클릭해 **Windows 시작 시 실행** 을 켜면 부팅할 때 자동으로 뜹니다

새 버전이 나오면 알아서 받아 설치합니다. 원하지 않으면 트레이 메뉴에서 **자동 업데이트** 를 끄면 됩니다.

버전별 변경사항은 [변경 기록](CHANGELOG.md)에서 확인할 수 있습니다.

## 사용

트레이 아이콘을 우클릭하면 다음을 할 수 있습니다.

- **상세 보기** — 각 한도의 사용률과 제공되는 초기화 시각
- **변경 기록 (Changelog)** — 인터넷 연결 없이 프로그램에 포함된 변경 기록 확인
- **인터페이스 설정** — 위젯 표시 토글, 원형 모드, 남은 시간 표시
- **Agent 설정 → 주간 초기화 시 자동 깨우기 (Codex)** — 기본 켜짐, 주간 사용률이 0%로 초기화되면 시간·요일과 관계없이 한 번 요청 (CLI 필요)
- **Claude Code / Codex** — 한쪽만 쓴다면 나머지를 끌 수 있습니다
- **5시간 한도 / 주간 한도** — 보고 싶은 것만 표시
- **Windows 시작 시 실행** — 부팅 시 자동 실행

위젯을 더블클릭해도 상세 창이 열립니다.
상세·변경 기록·위치 조정 창은 클릭한 트레이 또는 위젯 위에 표시됩니다.

## 알아두면 좋은 것

- **사용량 조회는 토큰이나 크레딧을 소모하지 않습니다.** 미리 깨우기·주간 자동 깨우기는 짧은 CLI 요청을 보내므로 소량의 사용량이 발생합니다
- Claude 로컬 기록은 5초마다 확인하며 실제 기록 갱신은 약 15분 간격입니다. Codex는 약 2분마다 조회합니다
- Codex 로그인이 풀리면 상세 창의 **로그인** 버튼으로 다시 로그인할 수 있습니다

## 필요한 것

- Windows 10 또는 11
- Claude는 로그인된 공식 데스크톱 앱이 백그라운드에서 실행 중이어야 합니다
- Codex는 지원되는 인증 저장소에 해당 계정으로 로그인돼 있어야 합니다

Claude는 공식 데스크톱 앱에서 로그인합니다. Codex는 앱 또는 `codex login` 명령으로 로그인합니다. 트레이 아이콘을 더블클릭해 상세 창을
열면 필요한 버튼이 떠 있습니다.

- **CLI 설치** — 명령이 없을 때. 누르면 새 창에서 설치가 진행되고, 끝나면 그 자리에서
  바로 로그인으로 이어집니다 (Node.js 가 없으면 함께 설치합니다)
- **로그인** — 명령은 있는데 로그인이 풀렸을 때

쓰지 않는 쪽을 마음대로 설치하지 않습니다. 버튼을 누를 때만 받습니다.

> Claude는 앱의 사용량 기록만 읽습니다. ChatGPT 로그인과 Codex 로그인은 별개입니다.

둘 중 하나만 써도 괜찮습니다. 트레이 메뉴에서 쓰지 않는 쪽을 끄면 됩니다.
