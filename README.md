# AI Usage Tray

Windows 작업표시줄에 **Claude Code** 와 **Codex** 의 한도 사용량을 표시하는 트레이 위젯.

![위젯](https://img.shields.io/badge/platform-Windows-blue)

```
 ✳  H 22%  ▬▬        W 58%  ▬▬▬▬▬
 >_                  W 65%  ▬▬▬▬▬▬
```

`H` = 5시간 한도, `W` = 주간 한도. 알림 영역(시계) 왼쪽, 작업표시줄 안쪽에 붙어 있다.

## 설치

1. [usage_tray.exe](usage_tray.exe) 를 받아 원하는 폴더에 둔다 (예: `C:\Tools\ai-usage-tray\`)
2. 더블클릭해서 실행한다. Python 설치는 필요 없다
3. 트레이 아이콘 우클릭 → **Windows 시작 시 실행** 을 켜면 부팅 때 자동으로 뜬다

업데이트는 앱이 알아서 받는다 (아래 참고). exe 를 옮기면 자동 시작을 다시 켜야 한다.

## 값을 어디서 가져오나

둘 다 **실시간 조회**다. 로컬 로그는 마지막 실행 시점 기록일 뿐이라 쓰지 않는다.

| 제공자 | 방식 | 비고 |
|---|---|---|
| Claude Code | `api.anthropic.com/api/oauth/usage` | `/usage` 와 같은 엔드포인트. `~/.claude` 의 토큰을 쓴다 |
| Codex | `codex app-server` 의 `account/rateLimits/read` | `/status` 와 같은 값. Codex CLI 가 설치돼 있어야 한다 |

**토큰이나 크레딧을 소비하지 않는다.** 모델 호출이 아니라 메타데이터 조회다.

기본 갱신 주기는 60초다. Claude 쪽은 실측상 약 1분에 1회만 허용되므로 더 짧게 둘 이유가 없다.
**PC 가 잠겨 있으면 조회를 멈추고**, 잠금이 풀리면 즉시 갱신한다.

조회에 실패하면 추정하지 않고 마지막 실측값을 기준 시각과 함께 보여주며, 위젯에서는 흐리게
그려 실시간 값과 구분한다.

## 자동 업데이트

1시간마다 이 저장소의 `version.json` 을 확인한다.

- **자동 업데이트 켬 (기본)** — 새 버전이 있으면 바로 받아 교체하고 재시작한다
- **끔** — 새 버전이 있다는 알림만 띄운다. 트레이 메뉴의 `업데이트 설치` 로 직접 설치한다

트레이 메뉴의 **자동 업데이트** 에서 바꿀 수 있다.

## 트레이 메뉴

| 항목 | 설명 |
|---|---|
| 상세 보기 | 각 한도의 전체 이름, 사용률, 리셋 시각 |
| 지금 갱신 | 즉시 다시 조회 |
| Claude Code / Codex | 제공자별 표시 켜고 끄기 (한쪽만 구독한다면) |
| 5시간 한도 (H) / 주간 한도 (W) | 표시할 한도 선택 |
| 화면 오버레이 표시 | 작업표시줄 위젯 켜고 끄기 |
| 잠금 시 갱신 중단 | 잠금 화면에서 조회 멈춤 |
| 작업표시줄에 붙이기 | 끄면 아무 곳으로나 드래그 가능 |
| 자동 업데이트 | 위 참고 |
| Windows 시작 시 실행 | 시작 폴더에 런처 등록 |

로그인 세션이 풀리면 `Claude Code 로그인...` / `Codex 로그인...` 항목이 메뉴에 나타난다.

## 설정 파일

`%APPDATA%\ai-usage-tray\config.json` — 갱신 주기, 표시 항목, 위젯 위치·색상 등.
자세한 항목은 소스 저장소의 README 를 참고.

## 요구 사항

- Windows 10/11
- Claude 사용량을 보려면 Claude Code 로그인 상태
- Codex 사용량을 보려면 Codex CLI 설치 + 로그인 상태
