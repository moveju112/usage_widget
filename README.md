# AI Usage Tray

Windows 작업표시줄에 **Claude Code** 와 **Codex** 의 사용량을 보여주는 작은 위젯입니다.

```
 ✳  H 22%  ▬▬        W 58%  ▬▬▬▬▬
 >_                  W 65%  ▬▬▬▬▬▬
```

시계 왼쪽, 작업표시줄 안에 붙어 있습니다. `H` 는 5시간 한도, `W` 는 주간 한도입니다.
50% 미만은 초록, 75% 미만은 노랑, 90% 이상은 빨강으로 표시됩니다.

## 설치

1. [usage_tray.exe](usage_tray.exe) 를 받아 원하는 폴더에 둡니다
2. 더블클릭하면 실행됩니다 — Python 설치는 필요 없습니다
3. 트레이 아이콘을 우클릭해 **Windows 시작 시 실행** 을 켜면 부팅할 때 자동으로 뜹니다

새 버전이 나오면 알아서 받아 설치합니다. 원하지 않으면 트레이 메뉴에서 **자동 업데이트** 를 끄면 됩니다.

## 사용

트레이 아이콘을 우클릭하면 다음을 할 수 있습니다.

- **상세 보기** — 각 한도의 사용률과 리셋까지 남은 시간
- **Claude Code / Codex** — 한쪽만 쓴다면 나머지를 끌 수 있습니다
- **5시간 한도 / 주간 한도** — 보고 싶은 것만 표시
- **Windows 시작 시 실행** — 부팅 시 자동 실행

위젯을 더블클릭해도 상세 창이 열립니다.

## 알아두면 좋은 것

- **사용량을 소모하지 않습니다.** 남은 한도를 물어보는 것뿐이라 토큰이나 크레딧이 들지 않습니다
- 1분마다 갱신하고, **PC 가 잠기면 멈췄다가** 잠금이 풀리면 바로 갱신합니다
- 로그인이 풀리면 트레이 메뉴에 **로그인** 항목이 나타납니다

## 필요한 것

- Windows 10 또는 11
- Claude Code / Codex 에 **로그인**돼 있어야 합니다

로그인은 `claude` 와 `codex` 명령으로 합니다. 이 명령이 없으면 처음 실행할 때
알아서 설치합니다 (Node.js 가 필요하고, 새 창에서 진행 상황이 보입니다).
설치가 끝나면 트레이 메뉴의 **로그인** 항목을 누르세요.

> Claude Code 앱이나 ChatGPT 앱에서 한 로그인은 여기에 쓸 수 없습니다.
> 그 앱들은 로그인을 자기 안에만 저장합니다.

둘 중 하나만 써도 괜찮습니다. 트레이 메뉴에서 쓰지 않는 쪽을 끄면 됩니다.
